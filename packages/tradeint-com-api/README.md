# tradeint-com-api

Python client and reference package for [TradeInt](https://www.tradeint.com) — Global Trade Intelligence Platform.

[![PyPI version](https://img.shields.io/badge/pypi-v0.1.0-blue.svg)](https://pypi.org/project/tradeint-com-api/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
`tradeint-com-api` provides Python developers with a lightweight client interface and reference helpers for [TradeInt](https://www.tradeint.com) trade intelligence workflows, shipment analysis, and market research.

* **Official Portal**: [https://www.tradeint.com](https://www.tradeint.com)
* **Resources**: [https://www.tradeint.com/resources/](https://www.tradeint.com/resources/)
* **Global Trade Insights**: [https://tradeint.com/insights/blogs/](https://tradeint.com/insights/blogs/)
* **Source Repository**: [https://github.com/ttt-tom/tradeint-python-sdk](https://github.com/ttt-tom/tradeint-python-sdk)

## Installation

```bash
pip install tradeint-com-api
```
