# tradeint-vn-api

Python client and reference package for [TradeInt Vietnam](https://tradeint.vn).

[![PyPI version](https://img.shields.io/badge/pypi-v0.1.0-blue.svg)](https://pypi.org/project/tradeint-vn-api/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
`tradeint-vn-api` provides Python developers with a lightweight client interface and reference helpers for [TradeInt Vietnam](https://tradeint.vn) import-export intelligence, market research, and supplier-buyer discovery workflows.

* **Official Portal**: [https://tradeint.vn](https://tradeint.vn)
* **Platform Features**: [https://tradeint.vn/features/](https://tradeint.vn/features/)
* **Vietnam Trade News**: [https://tradeint.vn/news/](https://tradeint.vn/news/)
* **Source Repository**: [https://github.com/ttt-tom/tradeint-python-sdk](https://github.com/ttt-tom/tradeint-python-sdk)

## Installation

```bash
pip install tradeint-vn-api
```
